Abstract

Reward fine-tuning aims to update a pre-trained flow-based generative model to improve the downstream reward of its generated samples. Existing methods typically formulate this problem as sampling from a reward-tilted distribution, the solution to a KL-regularized reward-maximization problem. Here, we introduce an optimal transport regularizer built directly from the pre-trained drift. Unlike KL reward tilting, the resulting objective transports individual samples toward higher reward rather than reweighting the base distribution.

We show that the resulting problem is equivalent to a deterministic optimal control problem on the flow. Given a pre-trained flow map, this equivalence yields a simulation-free reinforcement learning algorithm for fine-tuning generative flows. We call the resulting framework Wasserstein-Tilted Flow Maps (WTF), the first end-to-end fine-tuning recipe native to flow maps. The output is a fine-tuned flow map that retains strong reward-aligned performance at few-step inference budgets without post-hoc distillation. Experiments on ImageNet-256 and text-to-image show that WTF achieves higher reward with comparable or higher diversity than baselines, while requiring up to 280× less training compute.

More broadly, we argue that accelerated samplers such as flow maps are essential infrastructure for efficient post-training, and that the dominant KL-regularized formulation is only one of many choices worth revisiting.

Method

An optimal transport regularizer

Reward fine-tuning seeks a terminal distribution that increases the expected reward while staying close to the pre-trained model,

$$\tilde\rho_1=\arg\max_{\nu}\ \lambda\,\mathbb{E}_{x\sim\nu}[r(x)]-\mathcal{R}(\nu).$$

The usual choice $\mathcal{R}(\nu)=\mathrm{KL}(\nu\,\|\,\rho_1)$ gives the reward-tilted distribution $\tilde\rho_1\propto e^{\lambda r}\rho_1$, which reweights the base distribution. Its pathwise form is tractable for diffusions, so existing methods fine-tune a diffusion surrogate of the flow with many-step stochastic rollouts. We define $\mathcal{R}$ through the deterministic flow itself. The cost $c_b$ is the least residual control energy needed to steer the pre-trained drift $b_t$ from $x$ to $y$, and the regularizer is the corresponding transport problem from the prior $\rho_0$.

$$\mathcal{T}_b(\rho_0,\nu)=\inf_{\pi\in\Pi(\rho_0,\nu)}\int c_b(x,y)\,\pi(dx\,dy),\qquad c_b(x,y)=\inf_{\omega_0=x,\ \omega_1=y}\ \frac12\int_0^1\big\|\dot\omega_t-b_t(\omega_t)\big\|^2dt$$

With $b\equiv 0$ the regularizer reduces to $\tfrac12 W_2^2(\rho_0,\nu)$.

By Kantorovich duality, the problem decouples over source samples,

$$\sup_{\nu}\Big\{\lambda\,\mathbb{E}_{\nu}[r]-\mathcal{T}_b(\rho_0,\nu)\Big\} =\mathbb{E}_{x\sim\rho_0}\Big[\sup_{y}\big\{\lambda\, r(y)-c_b(x,y)\big\}\Big],$$

so each source sample moves to the endpoint that maximizes $\lambda r(y)-c_b(x,y)$. A reward tilt preserves the density ratio of any two points with equal reward, while transport can move mass between them.

Algorithm

Solving the optimal control problem

The per-sample decomposition characterizes the optimum but does not give a training algorithm. The problem is equivalent to a deterministic optimal control problem, which we solve by policy iteration using a pre-trained flow map.

An equivalent optimal control problem

$$\sup_{u}\ \mathbb{E}_{x_0\sim\rho_0}\Big[\lambda\, r(x_1^u)-\frac12\int_0^1\|u_t(x_t^u)\|^2dt\Big] \quad\text{s.t.}\quad \dot x_t^u=b_t(x_t^u)+u_t(x_t^u)$$

The Wasserstein-tilted objective has the same optimal value as this control problem, and its optimal control $u^*$ produces the Wasserstein-tilted distribution. The optimal model is again a single drift $b_t+u^*_t$, which replaces $b_t$ at inference.

The optimal control is the gradient of the optimal value, $u^*_t=\nabla_x V^*_t$. Policy iteration regresses the trainable control onto the value gradient $\nabla_x V^{\bar u}$ of a frozen reference $\bar u$ and then updates the reference. At the population level, a performance-difference identity shows that each step improves the objective until the fixed point, which is the optimal control.

Simulation-free value estimation

The value gradient normally requires simulating and backpropagating through the entire future trajectory, or training a critic to approximate it. A pre-trained flow map jumps between any two times in one evaluation.

Actor-critic

forward calls 0

A learned critic predicts the value in one call, so the estimate is only as good as the critic.

  • O(1)
  • biased
  • needs a critic

Multi-step rollout

forward calls 0

The flow is simulated for $T$ steps and differentiated through all of them, so every update pays for the whole trajectory.

  • unbiased
  • O(T) calls
  • O(T) memory

WTF (ours)

forward calls 0

Two flow-map jumps reach $x_1$ from $x_t$, and one Jacobian backprop returns the value gradient.

  • unbiased
  • O(1)
  • no critic

Writing the remaining control cost as an average over a uniformly sampled time $\tau$ gives an unbiased single-sample estimate of the value, with both states produced by flow-map jumps.

$$\widehat V(t,x)=\lambda\, r(x_1)-\frac{1-t}{2}\,\big\|\bar u_\tau(x_\tau)\big\|^2,\qquad \tau\sim\mathrm{U}[t,1],\quad x_\tau=X^{\bar u}_{t,\tau}(x),\quad x_1=X^{\bar u}_{\tau,1}(x_\tau)$$

The flow map gives $x_1$ without simulating the trajectory, so the only Monte Carlo approximation is the scalar time integral.

The WTF objective

$$\mathcal{L}_{\mathrm{WTF}}(\hat w)=\mathbb{E}\Big[\big\|\hat w_{t,t}(\bar x_t)-b_t(\bar x_t)-\nabla_x\widehat V(t,\bar x_t)\big\|^2\Big] +\beta\,\mathcal{L}_{\mathrm{dist}}(\hat w),\qquad \bar w=\mathrm{sg}(\hat w)$$

Value-gradient regression on the diagonal, flow map self-distillation off the diagonal. Distillation keeps the output a flow map, and that flow map keeps supplying amortized on-policy rollouts for the next value estimate.

One training step of WTF

  1. Sample $x_0\sim\rho_0$, $t\sim\mathrm{U}[0,1]$, $\tau\sim\mathrm{U}[t,1]$.
  2. Jump with the frozen flow map to $\bar x_t=X^{\bar w}_{0,t}(x_0)$, $\bar x_\tau=X^{\bar w}_{t,\tau}(\bar x_t)$ and $\bar x_1=X^{\bar w}_{\tau,1}(\bar x_\tau)$.
  3. Estimate the value $\widehat V$ and backpropagate once to get $\widehat g=\nabla_{\bar x_t}\widehat V$.
  4. Regress $\hat w_{t,t}(\bar x_t)$ onto $b_t(\bar x_t)+\widehat g$ and add the self-distillation loss.

At the population level every fixed point is the optimal control, and the output remains a flow map.

Results

Reward and training compute

We fine-tune DMF-XL/2 on ImageNet-256 and TiM-T2I for text-to-image, both against HPSv2, using the Euclidean reward gradient that drops the flow-map Jacobian from the reward term. WTF achieves higher reward with comparable or higher diversity than the baselines, and the same fine-tuned flow map remains effective at few steps without post-hoc distillation.
