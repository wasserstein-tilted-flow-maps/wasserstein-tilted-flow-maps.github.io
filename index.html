Simulation-Free Reinforcement Learning

Reward fine-tuning that transports samples toward high reward instead of reweighting them, and trains the flow map itself, end to end, without simulating the flow.

Abstract

Fine-tune the flow, not a diffusion surrogate

Reward fine-tuning aims to update a pre-trained flow-based generative model to improve the downstream reward of its generated samples. Existing methods typically formulate this problem as sampling from a reward-tilted distribution, the solution to a KL-regularized reward-maximization problem. Here, we introduce an optimal transport regularizer built directly from the pre-trained drift. Unlike KL reward tilting, the resulting objective transports individual samples toward higher reward rather than reweighting the base distribution.

We show that the resulting problem is equivalent to a deterministic optimal control problem on the flow. Given a pre-trained flow map, this equivalence yields a simulation-free reinforcement learning algorithm for fine-tuning generative flows. We call the resulting framework Wasserstein-Tilted Flow Maps (WTF), the first end-to-end fine-tuning recipe native to flow maps. The output is a fine-tuned flow map that retains strong reward-aligned performance at few-step inference budgets without post-hoc distillation. Experiments on ImageNet-256 and text-to-image show that WTF achieves higher reward with comparable or higher diversity than baselines, while requiring up to 280× less training compute.

More broadly, we argue that accelerated samplers such as flow maps are essential infrastructure for efficient post-training, and that the dominant KL-regularized formulation is only one of many choices worth revisiting.

Method

Transport, don't reweight

The usual target $\tilde\rho_1 \propto e^{\lambda r}\rho_1$ comes from a KL regularizer: it can only reweight mass the base model already places. We instead measure deviation from the base model by how much the pre-trained dynamics must be steered: an optimal transport cost built from the drift itself.

KL reward tilt

Reweights the base distribution. Its pathwise form is tractable for diffusions via Girsanov, so existing methods convert the flow into a diffusion, fine-tune the diffusion, and convert back, paying for many-step stochastic rollouts along the way.

Wasserstein tilt (ours)

Moves each sample to its best reward–cost tradeoff. The cost depends only on the deterministic flow, so the problem becomes deterministic optimal control, which a flow map can solve without simulating the dynamics.

From a regularizer to an algorithm

1 An optimal transport regularizer from the pre-trained drift $$c_b(x,y)=\inf_{\omega_0=x,\ \omega_1=y}\ \frac12\int_0^1\big\|\dot\omega_t-b_t(\omega_t)\big\|^2dt,$$ $$\mathcal{T}_b(\rho_0,\nu)=\inf_{\pi\in\Pi(\rho_0,\nu)}\int c_b(x,y)\,\pi(dx\,dy)$$

$c_b$ is the minimum residual energy needed to steer a particle from $x$ to $y$ while following the pre-trained drift $b_t$. With $b\equiv 0$ it reduces to $\tfrac12 W_2^2$.

2 The objective decouples per sample $$\sup_{\nu}\Big\{\lambda\,\mathbb{E}_{\nu}[r]-\mathcal{T}_b(\rho_0,\nu)\Big\} =\mathbb{E}_{x\sim\rho_0}\Big[\sup_{y}\big\{\lambda\, r(y)-c_b(x,y)\big\}\Big]$$

Every source sample travels to its own best destination: transport, not global reweighting.

3 It is deterministic optimal control $$\sup_{u}\ \mathbb{E}_{x_0\sim\rho_0}\Big[\lambda\, r(x_1^u)-\frac12\int_0^1\|u_t(x_t^u)\|^2dt\Big], \qquad \dot x_t^u=b_t(x_t^u)+u_t(x_t^u)$$

The fine-tuned model is again a single drift $b_t+u^*_t$, and this problem is the rescaled zero-noise limit of the stochastic control used for reward tilting.

Simulation-free value estimation

Policy iteration regresses the control onto the value gradient of a frozen reference. A pre-trained flow map jumps between any two times in one evaluation, so the value needs no rollout and no critic.

4 An $O(1)$ Monte Carlo value estimate $$\widehat V(t,x)=\lambda\, r(x_1)-\frac{1-t}{2}\,\big\|\bar u_\tau(x_\tau)\big\|^2,$$ $$\tau\sim\mathrm{U}[t,1],\quad x_\tau=X^{\bar u}_{t,\tau}(x),\quad x_1=X^{\bar u}_{\tau,1}(x_\tau)$$

The only randomness is a one-dimensional time integral, not the high-dimensional expectation behind stochastic value functions.

5 The WTF training objective $$\mathcal{L}_{\mathrm{WTF}}(\hat w)=\mathbb{E}\Big[\big\|\hat w_{t,t}(\bar x_t)-b_t(\bar x_t)-\nabla_x\widehat V(t,\bar x_t)\big\|^2\Big] +\beta\,\mathcal{L}_{\mathrm{dist}}(\hat w),\qquad \bar w=\mathrm{sg}(\hat w)$$

Value gradient regression on the diagonal, plus flow map self-distillation off the diagonal: the output stays a flow map, and the flow map keeps supplying amortized on-policy rollouts. Every population fixed point is the optimal control.
